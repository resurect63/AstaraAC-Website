## About AstaraAC

AstaraAC is a security platform currently under development.

Its goal is to bring multiple security capabilities together
in one ecosystem, including:

- Advanced Anti-Cheat Detection
- PC Forensics
- Forensic Screenshare
- Windows Desktop Scanner
- Centralized Web Dashboard
- Minecraft Server Integrations
- REST API and WebSocket infrastructure
- Discord Integration

## Security & Privacy

AstaraAC is designed around transparent and authorized
security analysis.

- User consent is important.
- Investigations should be transparent.
- Unrelated private information should not be collected.
- Detection results should support human review.
